# 햄스터 캐릭터 제작 규격서

## 1. 문서 목적

본 문서는 햄스터 육성 게임에서 사용하는 모든 햄스터 캐릭터의 외형, 크기, 색상, 무늬, 애니메이션 제작 기준을 정의한다.

모든 햄스터는 동일한 기본 몸체와 얼굴 구조를 공유하며, 털 색상과 무늬만 변경하는 방식으로 제작한다.

이를 통해 다음 사항을 보장한다.

* 캐릭터별 크기와 비율 통일
* 행동 전환 시 위치 흔들림 방지
* 색상별 애니메이션 제작 비용 절감
* 신규 햄스터 외형 추가 용이
* 모바일과 PC에서 동일한 품질 유지

참고 이미지는 디자인 방향을 위한 자료이며, 게임에서 직접 사용하는 최종 에셋은 별도로 제작한다.

# 3. 공통 캐릭터 제작 규격

## 3.1 기본 캔버스

| 항목       | 기준        |
| -------- | --------- |
| 캔버스 크기   | 64×64px   |
| 파일 형식    | PNG       |
| 배경       | 투명        |
| 색상 모드    | RGBA      |
| 안티앨리어싱   | 사용하지 않음   |
| 외곽선      | 짙은 갈색 1px |
| 캐릭터 중심   | x=32px    |
| 발 기준선    | y=57px    |
| 좌우 최소 여백 | 5px       |
| 상단 최소 여백 | 4px       |
| 확대 방식    | 정수 배율     |

캐릭터의 귀, 발, 행동 소품을 포함하더라도 캔버스 밖으로 나가지 않도록 한다.

---

## 3.2 기본 몸체 비율

모든 외형은 동일한 기본 몸체를 사용한다.

* 머리와 몸통 경계가 명확하지 않은 둥근 형태
* 몸 전체는 세로보다 가로가 약간 넓은 타원형
* 귀는 머리 위쪽 양끝에 작고 둥글게 배치
* 배 부분은 몸통 중앙 아래쪽에 밝은 색으로 표현
* 앞발은 배 양쪽에 작게 배치
* 뒷발은 몸통 아래쪽 바깥 방향에 배치
* 꼬리는 기본 정면 자세에서 표시하지 않음
* 볼은 기본 상태에서는 작게 유지
* 먹기 또는 볼 저장 행동에서만 볼 크기를 확대

외형별로 몸의 크기나 귀 크기를 다르게 만들지 않는다.

---

## 3.3 얼굴 위치

모든 햄스터에서 얼굴의 위치를 동일하게 유지한다.

| 요소    | 기준              |
| ----- | --------------- |
| 왼쪽 눈  | 중심 기준 왼쪽 5~7px  |
| 오른쪽 눈 | 중심 기준 오른쪽 5~7px |
| 코     | 캐릭터 중심선         |
| 입     | 코 아래 1~2px      |
| 귀     | 좌우 대칭           |
| 눈 크기  | 1~2px           |
| 코 크기  | 1~2px           |

정확한 좌표는 기준 골든 스프라이트가 확정된 후 고정한다.

### 눈

* 검은색 또는 매우 짙은 갈색
* 얼굴 크기에 비해 작게 표현
* 눈동자 하이라이트는 사용하지 않거나 1픽셀 이하로 제한
* 기본 상태에서는 양쪽 눈 크기를 동일하게 유지

### 코

* 핑크색 사용
* 얼굴 중앙에 배치
* 모든 외형에서 동일한 색상을 사용
* 털 색상이 달라져도 코 색상은 변경하지 않음

### 입

* 기본 상태에서는 생략하거나 1픽셀로 표현
* 먹기, 웃기, 쓰다듬기 반응 등 필요한 행동에서만 표시

# 4. 공통 팔레트 구조

모든 캐릭터는 다음 의미 기반 팔레트를 사용한다.

```typescript
type HamsterPalette = {
  outline: string;
  eye: string;
  nose: string;
  earInner: string;
  foot: string;

  furMain: string;
  furLight: string;
  furShadow: string;
  furDeepShadow: string;

  bellyMain: string;
  bellyShadow: string;

  markingMain?: string;
  markingShadow?: string;
};
```

각 색상은 단순한 이미지 위치가 아니라 역할을 기준으로 관리한다.

예를 들어 골든 햄스터의 `furMain` 픽셀은 그레이 햄스터를 만들 때 `gray.furMain`으로 치환한다.

# 5. MVP 햄스터 외형 7종

## 5.1 골든 햄스터

### 식별 정보

* 캐릭터 ID: `GOLDEN`
* 파일 폴더명: `golden`
* 역할: 전체 햄스터의 기준 캐릭터
* 기본 선택 외형: 사용 가능

### 외형 특징

* 등과 머리는 밝은 주황빛 골드
* 얼굴 아래쪽과 배는 밝은 크림색
* 귀 주변은 몸 색보다 약간 어둡게 표현
* 볼 바깥쪽까지 골드 털을 유지
* 배 무늬는 좌우 대칭

### 권장 팔레트

| 역할     | 색상        |
| ------ | --------- |
| 털 기본색  | `#D9913D` |
| 털 밝은색  | `#F2B95F` |
| 털 그림자  | `#B86E31` |
| 깊은 그림자 | `#84502B` |
| 배 기본색  | `#FFF0D2` |
| 배 그림자  | `#E8CDA6` |

### 제작 기준

* 가장 먼저 완성하는 기준 스프라이트
* 모든 행동 프레임은 골든 버전으로 먼저 제작
* 다른 색상은 골든의 픽셀 위치를 그대로 유지
* 골든만 별도로 몸 형태를 수정하지 않음

# 6. 외형별 차이 제한

MVP 7종은 색상만 변경하고 다음 요소는 변경하지 않는다.

* 몸 크기
* 몸 비율
* 귀 크기
* 눈 크기
* 눈 위치
* 코 크기
* 코 위치
* 앞발 위치
* 뒷발 위치
* 배 무늬 모양
* 행동별 프레임 수
* 애니메이션 재생 속도

다음 요소는 MVP 이후 특수 외형에서만 변경한다.

* 등줄 무늬
* 얼굴 중앙 줄무늬
* 반점
* 턱시도 무늬
* 장모
* 루비색 눈
* 특수 귀 색상
* 서로 다른 배 무늬

# 7. 행동별 제작 규격

모든 외형은 동일한 행동 목록을 가져야 한다.

| ----------- | -------- | -----: | ---- |
| `IDLE`      | 기본 대기    |      4 | 반복   |
| `WALK`      | 걷기       |      6 | 반복   |
| `LOOK`      | 서서 둘러보기  |      4 | 1~2회 |
| `EAT`       | 먹기       |      6 | 반복   |
| `DRINK`     | 물 마시기    |      6 | 반복   |
| `SLEEP`     | 잠자기      |      4 | 반복   |
| `WHEEL`     | 쳇바퀴 타기   |      6 | 반복   |
| `PET`       | 쓰다듬기 반응  |      4 | 1회   |
| `WASH`      | 세수하기     |      6 | 반복   |
| `CHEEK`     | 볼에 저장    |      4 | 1회   |

# 8. 행동 공통 기준

## 8.1 기준선 유지

모든 행동에서 발 기준선을 유지한다.

```text
캐릭터 중심: x=32px
기본 발 기준선: y=57px
```

점프하거나 넘어지는 특수 행동이 아닌 이상 캐릭터의 위치가 위아래로 이동하지 않게 한다.

## 8.2 얼굴 유지

행동이 바뀌더라도 다음 요소는 가능한 한 동일한 위치를 유지한다.

* 눈
* 코
* 귀
* 배 중심
* 몸통 중심

먹기, 잠자기, 측면 이동처럼 자세가 크게 바뀌는 경우에만 예외를 허용한다.

## 8.3 좌우 방향

오른쪽 방향 스프라이트를 기본 제작하고, 왼쪽 이동은 코드에서 좌우 반전한다.

```css
transform: scaleX(-1);
```

단, 다음 요소가 포함된 경우 별도 좌우 에셋이 필요할 수 있다.

* 한쪽에만 있는 무늬
* 방향성이 있는 소품
* 글자가 포함된 소품

MVP 7종은 좌우 대칭 외형이므로 반전 방식을 사용한다.

# 11. 색상 치환 제작 순서

## 1단계

골든 햄스터의 모든 행동 프레임을 제작한다.

```text
골든 기본 몸체
→ 대기
→ 걷기
→ 먹기
→ 물 마시기
→ 잠자기
→ 나머지 행동
```

## 2단계

골든 팔레트 픽셀을 의미별로 분류한다.

```text
털 기본색
털 밝은색
털 그림자
털 깊은 그림자
배 기본색
배 그림자
```

## 3단계

그레이·화이트·베이지·브라운·차콜·크림 팔레트로 자동 치환한다.

## 4단계

색상별 결과를 사람이 검수한다.

특히 다음 외형은 자동 치환 후 수동 보정이 필요할 가능성이 크다.

* 화이트: 배경과 경계가 흐려질 수 있음
* 차콜: 외곽선과 몸 색상이 합쳐질 수 있음
* 크림: 화이트 또는 베이지와 비슷해질 수 있음

# 13. 제작 완료 검수 기준

각 외형은 다음 기준을 모두 충족해야 한다.

## 공통 형태

* 64×64px 캔버스를 사용했는가
* 투명 배경인가
* 안티앨리어싱이 없는가
* 외곽선이 1px로 유지되는가
* 캐릭터 중심이 x=32px에 맞는가
* 발 기준선이 행동 사이에서 유지되는가
* 눈과 코 위치가 외형별로 동일한가

## 색상

* 골든과 브라운이 명확히 구분되는가
* 그레이와 차콜이 명확히 구분되는가
* 화이트와 크림이 명확히 구분되는가
* 베이지와 크림이 명확히 구분되는가
* 차콜에서도 눈과 얼굴이 식별되는가
* 화이트에서도 몸의 형태가 식별되는가

## 애니메이션

* 행동 전환 시 캐릭터가 흔들리지 않는가
* 프레임별 몸 크기가 달라지지 않는가
* 색상 치환 후 누락된 픽셀이 없는가
* 코와 눈이 색상 치환 대상에서 제외됐는가
* 좌우 반전 시 외형이 어색하지 않은가
